# 《小刺猬的秋天信》TTS 剧本

【场景一：树洞清晨】
[音色:冰糖]
（温暖讲故事语气）
小刺猬醒来了。

阳光钻进树洞，暖洋洋的。

小刺猬伸个懒腰，闻到了味儿。

是秋天的味儿。

[音色:茉莉]
（惊喜、雀跃）
秋天来了！

【场景二：松鼠家门口】
[音色:冰糖]
（轻快）
他跑到松鼠阿松家。

[音色:茉莉]
（兴奋、大声）
阿松，秋天来了！

[音色:冰糖]
（叙述）
阿松正忙着藏松果，听见了，探出头。

[音色:白桦]
（惊讶、期待）
真的吗？

[音色:茉莉]
（认真、温柔）
真的！我给你写封信。

【场景三：树洞里写信】
[音色:冰糖]
（平缓叙述）
小刺猬跑回家，找来一片大树叶。

他用松果壳蘸着露水，在树叶上画画。

画了一颗红红的苹果。

画了一片金黄的银杏叶。

画了一个圆圆的太阳。

旁边写上：秋天真好。

（呼呼——风声）

小刺猬把树叶信塞进树洞口。

风一吹，树叶信飞呀飞。

飞到了阿松脚边。

【场景四：阿松收到信】
[音色:冰糖]
（温和）
阿松捡起来，看了一眼，笑了。

[音色:白桦]
（感动、温暖）
谢谢你，小刺猬。

[音色:冰糖]
（轻快）
阿松抱起一堆松果，跑过来。

[音色:白桦]
（大方、开心）
这是给你的秋天礼物。

[音色:茉莉]
（满足、幸福）
小刺猬抱着松果，心里暖乎乎的。

他想：还有谁想收到秋天信呢？

【场景五：第二封信】
[音色:冰糖]
（愉快）
他又画了一片树叶信。

画了一颗紫葡萄，一只飞舞的蝴蝶。

（呼呼——风声）

这封信飞呀飞，飞到了小鸟叽叽窝里。

【场景六：小鸟叽叽唱歌】
[音色:冰糖]
（叙述）
叽叽叼着树叶信，唱起了歌。

[音色:苏打]
（清亮、歌唱感）
秋天真美，秋天真甜。

[音色:冰糖]
（叙述）
小刺猬听见了，也跟着哼起来。

[音色:茉莉]
（轻快、跟着哼唱）
啦啦啦……

【场景七：傍晚树根下】
[音色:冰糖]
（舒缓、温柔）
傍晚了，天边染红了云彩。

小刺猬坐在树根下，手里攥着两颗松果。

风吹过，树叶沙沙响。

（沙沙——树叶声）

像是在说：明天还要写信哦。

[音色:茉莉]
（会心、期待）
好呀，明天继续写。
