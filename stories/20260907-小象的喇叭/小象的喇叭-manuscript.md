# 《小象的喇叭》
- 目标年龄：3-6 岁
- 核心主题：每个孩子都有自己的长处，不用和别人一样

（正文开始）

森林里住着一头小象，名叫米奇。

米奇有一条长长的鼻子。他的鼻子很特别，别的长鼻子只能吹出声音——呜——呜——像喇叭一样响。可是米奇的鼻子只会喷水。

哗——！

"米奇，你的鼻子真没用！"一只小猴子跳到树枝上，"你看长颈鹿哥哥，吹起喇叭多响亮！"

米奇低下头，鼻子轻轻甩了甩。

"呜——呜——"长颈鹿哥哥在树荫下吹喇叭，声音又高又亮。

"呼——哗！"米奇试着吹，只喷出一股水花。

小动物们都笑了。连风也呼呼地笑。

米奇很难过。他躲到大树后面，一个人玩自己的长鼻子。

"如果我的鼻子也能吹喇叭就好了……"米奇小声说。

日子一天天过去。米奇还是不会吹喇叭，但他学会了用鼻子洒水。

下雨的时候，米奇的鼻子比谁都好用。哗啦啦，哗啦啦，小树小树喝水啦。

可是米奇还是不开心。他总觉得自己跟别的小象不一样。

有一天早上，米奇醒来，发现外面白茫茫的。

"怎么回事？"米奇瞪大眼睛。

原来，森林里起大雾了！

雾好大好大，像一床厚厚的被子把整个森林盖住了。小动物们睁开眼睛，什么也看不见。

"我的家在哪里呀？"小兔子哭着找妈妈。

"我看不见路了！"小鹿哥哥害怕地站在原地。

"呜呜呜——"大家都在哭，大家都在喊。

长颈鹿哥哥拿出喇叭。呜——呜——！

可是声音传不出去，雾把声音都吃掉了。

小猴子跳上树喊："谁能帮帮我们呀！"

米奇站在雾里，鼻子动了动。

"我有一个办法！"米奇喊道。

他深吸一口气——呼——呼——！

然后，米奇用鼻子吹出了一团团白白的雾气。雾气在浓雾里形成了一个个形状，就像用手指在墙上画画。

"跟我走！"米奇用鼻子指了一条路。

小兔子看见了，跟着米奇走过去。

"这边！"米奇又吹出一个箭头。

小鹿哥哥看见了，慢慢走过去。

一个接一个，小动物们都跟着米奇的鼻子走出了大雾。

最后，米奇吹出了一个大大的笑脸。所有动物都安全了！

"米奇，谢谢你！"小兔子抱住米奇的腿。

"米奇，你的鼻子太厉害了！"小猴子不好意思地说。

长颈鹿哥哥走过来，轻轻用脖子碰了碰米奇。

"你的鼻子吹喇叭的声音，比我的还好听。"长颈鹿哥哥说。

米奇笑了。他的鼻子开心地甩来甩去。

哗——呼——！

从那以后，森林里的小动物们再也不笑米奇的鼻子了。因为他们知道，米奇的鼻子是世界上独一无二的。

（正文完）

【教育意义】你不需要变成别人，你本身就很好。

【互动问题】如果你有一条神奇的鼻子，你最想用它做什么呢？
