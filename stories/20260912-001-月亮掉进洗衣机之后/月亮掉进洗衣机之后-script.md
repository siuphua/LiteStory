# 《月亮掉进洗衣机之后》TTS 剧本

【场景一：昨晚的意外】
[音色:冰糖]
（温柔讲故事语气）
天上有月亮，楼下有一台空空的洗衣机。它们本来是八竿子打不着的。直到昨天晚上，月亮洗完头发，打了一个趔趄。

（稍快一点，像在解释）
趔趄，就是身子一晃，差点摔倒。月亮是这么一晃，手里的半瓶银色月光，就全倒进了楼下那台空洗衣机里。

（轻快）
咚的一下，洗衣机自己转了起来。里面哗啦啦，全是银色的小星星一样的泡泡。

【场景二：清晨的发现】
[音色:冰糖]
（平静叙述）
第二天清早，王阿姨第一个喊出来：

[音色:茉莉]
（惊讶、带着笑意）
"我的睡衣怎么全是月牙！"

[音色:冰糖]
她晾出来的白睡衣上，印着弯弯的月牙，一闪一闪的。隔壁阳台，李叔叔的床单也挂出来了。

[音色:白桦]
（疑惑）
哎，床单上也是月牙，还是银亮银亮的。

[音色:冰糖]
再一看，晾衣绳上挂的袜子、毛巾、小裙子，一件接一件，全印上了弯弯的月牙图案。整栋楼的小朋友都趴在窗台上看。七岁的圆圆也挤在人群里。她踮起脚，往下一看——

（压低声音，制造悬念）
那台洗衣机，还在嗡嗡嗡地转。里面漂着一池银色的水，水上，有一个圆圆的光，正慢慢转圈。

[音色:茉莉]
（压低声音，惊奇）
"是月亮！月亮掉进去啦！"

[音色:冰糖]
大家都在笑，说怎么可能。可那光，就是月亮一模一样的形状。

【场景三：小小的守护者】
[音色:冰糖]
（轻柔）
圆圆搬来小板凳，趴在洗衣机口上看。里面的月亮转呀转，好像在说：

[音色:茉莉]
（模仿月亮的声音，软软糯糯）
"我回不去了，我卡在滚筒里啦。"

[音色:冰糖]
大家想了想。王阿姨把排水管拧开，放到楼下的水沟里。

（拟声）
（呼——哗啦啦——）

[音色:冰糖]
银色的水慢慢流出来。月亮跟着水流，溜到了水沟里。它在水沟里漂了漂，轻轻一弹，

（语速加快，像滑梯一样）
像坐上了滑梯，嗖的一下，飞上了屋顶。又嗖的一下，飞进了云里。再一眨眼，天上挂上了月亮，和以前一模一样。

【场景四：属于圆圆的小魔法】
[音色:冰糖]
（欢快）
大家都拍手。可是圆圆发现，她的那件小裙子，晾了一天，干了。裙子上的弯弯月牙，还在，银亮银亮的。

圆圆把裙子穿在身上，出门了。一路上，有小朋友问她：

[音色:茉莉]
（好奇）
"你的裙子，是不是昨晚去过天上？"

[音色:茉莉]
（歪头，神秘地笑）
"说不定哦。"

[音色:冰糖]
那天晚上，圆圆把裙子挂在窗边。月光照在裙子上，月亮图案一闪一闪。她对自己说：

[音色:茉莉]
（喃喃自语，温柔）
"你帮我看看，天上那个圆月亮，是不是在冲我做鬼脸。"

[音色:冰糖]
她没看清。不过没关系。第二天早上，她的小白鞋上，不知道什么时候，也印上了一个弯弯的月牙。

（尾声，放慢语速，温暖收束）
世界总有意外的小魔法，只要你愿意蹲下来看一看，普通的日子也能闪闪发亮。

[音色:茉莉]
（轻快，邀请互动）
如果月亮又掉进一台家用电器里，你想让它掉进哪一台？它会怎么出来呢？
