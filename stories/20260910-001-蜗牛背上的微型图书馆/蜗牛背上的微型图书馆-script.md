# 《蜗牛背上的微型图书馆》TTS 剧本

【场景一：清晨出发】
[音色:冰糖]
（温暖讲故事语气）
蜗牛慢慢爬，背上驮着个小书包。
书包里住着一座微型图书馆。
图书馆只有巴掌大，却装着无数个故事。

【场景二：遇见小兔子】
[音色:茉莉]
（疲惫、软糯）
蜗牛哥哥，我累了，不想跳了。

[音色:苏打]
（温和、耐心）
来，给你讲个《月亮摘星星》的故事。

[音色:冰糖]
（轻快、有画面感）
小兔子听着，眼睛亮了，脚底下又有了劲儿。

【场景三：遇见小松鼠】
[音色:白桦]
（着急、焦虑）
蜗牛哥哥，我找不到松果了。

[音色:苏打]
（从容、安抚）
来，给你讲个《风儿帮忙找宝贝》的故事。

[音色:冰糖]
（惊喜、生动）
小松鼠听着，耳朵竖起来，松果真滚到了脚边。

【场景四：遇见小刺猬】
[音色:茉莉]
（委屈、哭腔）
蜗牛哥哥，我没朋友，大家都怕扎手。

[音色:苏打]
（轻柔、靠近）
来，给你讲个《会发光的刺球》的故事。

[音色:冰糖]
（治愈、温暖）
小刺猬听着，刺儿软了，笑出了声。

【场景五：夕阳归途】
[音色:冰糖]
（舒缓、依依不舍）
太阳偏西，蜗牛该回家了。
三个小朋友围过来，不想让蜗牛走。

[音色:茉莉]
（期盼、依恋）
蜗牛哥哥，明天还来讲故事吗？

[音色:苏打]
（笃定、充满希望）
故事在背上，我在路上，只要你们在，图书馆就永远开着门。

【场景六：夜色收尾】
[音色:冰糖]
（宁静、如摇篮曲般柔和）
夜色温柔，蜗牛背着图书馆，慢慢爬回家。
月光洒在书脊上，故事在梦里悄悄生长。
