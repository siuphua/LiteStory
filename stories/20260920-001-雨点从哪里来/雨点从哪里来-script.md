# 《雨点从哪里来》TTS 剧本

【场景1：窗边的小满】

【冰糖：温柔，缓慢的旁白】
滴答，滴答。雨点敲着窗户，像许多小手指，轻轻敲门。小满搬来小板凳，趴在窗边问："雨点是从哪里来呀？"

【茉莉：好奇，声音清脆】
"妈妈，雨点是从哪里来的呀？"

【冰糖：旁白】
妈妈坐到她身边，说："雨点，是从云朵里来。"

【场景2：云朵的秘密】

【茉莉：惊讶，疑问】
"云朵里怎么会有雨点呢？"

【冰糖：温柔，解释的语气】
"云朵像一团湿湿的棉花，里面藏着许多小水珠。水珠越挤越多，挤不下了，就手拉手往下跳。跳下来，就成了雨点。"

【茉莉：好奇，追问】
"那小水珠又是从哪里来的？"

【冰糖：旁白，温暖】
妈妈指了指窗外，说："太阳照着大海，也照着小河、水坑。水被晒得暖暖的，就变成看不见的小水汽，轻飘飘飞上天。风把小水汽抱在一起，越抱越多，就抱成了一朵云。"

【场景3：雨点滑滑梯】

【茉莉：开心，发现】
"小水珠那么轻，怎么又会掉下来呢？"

【冰糖：旁白】
妈妈笑了笑："你看，云朵越来越厚，越来越灰。水珠越来越多，云朵托不住啦，它们就一起落下来。"

【茉莉：兴奋地拍手】
"哦！雨点是坐云朵的滑梯滑下来的！"

【场景4：雨点的旅行】

【冰糖：温柔，缓慢】
"那雨点落到地上以后呢？"

【茉莉：期待】
"它们还会回来吗？"

【冰糖：旁白，温暖】
妈妈点点头："有的钻进泥土，给小花小草喝水。有的汇成小溪，唱着歌跑远了。有的停在叶子上，等太阳出来，又飞回天上。会呀，下次下雨，你还会见到它们。"

【场景5：雨后的彩虹】

【音效：轻柔的雨声渐弱，鸟鸣声】

【冰糖：旁白，梦幻】
小满伸出小手，接住一滴雨。凉凉的，滑滑的，像一颗透明的糖。她举到耳边问："小雨点，你是从大海来的吗？"雨点不回答，只在她手心里轻轻跳了一下。

【冰糖：旁白，舒缓】
雨停了。太阳从云后探出头，天边架起一座彩虹桥。

【茉莉：开心，活泼】
小满跑到院子里，踩着小水坑，一下，两下，三下。妈妈站在门口，笑眯眯地看着她。

【冰糖：旁白，温馨】
一阵风吹过来，树叶上的雨点簌簌落下来，有一滴，刚好落在小满的鼻尖上。"啪！"

【茉莉：咯咯笑】
"妈妈，雨点又来看我啦！"

【冰糖：旁白，温柔收束】
妈妈笑着说："是呀。下次下雨，你再好好看看，雨点是从哪里来的。"小满点点头，抬头看天。云朵慢慢散开，像一群白白的小羊。她好像看见，许多小水珠正在云里排队，等着下一次旅行。

【冰糖：旁白，梦幻】
天边，彩虹越来越淡。小满挥挥手："小雨点，下次再见！"

【场景6：尾声】

【冰糖：轻柔，如睡前故事】
每个孩子都应该学会抬头看天，发现身边小小的变化。雨点不是天上硬"掉"下来的，而是小水珠在太阳、风和云朵之间的一次旅行。

【音效：轻柔的音乐渐弱】

【冰糖：最后一句，温柔】
下次下雨，你也会看见它们在云里排队，等着滑滑梯呢。
