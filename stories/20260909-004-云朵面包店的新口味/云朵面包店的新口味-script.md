# 《云朵面包店的新口味》TTS 剧本

【场景一：云朵面包店的清晨】
[音色:冰糖]
（温暖讲故事语气）
天上有家云朵面包店。

[音色:苏打]
（慈祥、慢条斯理）
店主是胖胖的云朵伯伯。

[音色:冰糖]
（轻快、有画面感）
他每天揉啊揉，捏啊捏。

把蓝天揉成白面包。

把夕阳捏成红面包。

把星星撒进甜面包。

【场景二：小鸟买早餐】
[音色:茉莉]
（清脆、期待）
小鸟飞来买早餐。

"伯伯，给我来个白云面包。"

[音色:冰糖]
（愉悦）
咬一口，软绵绵，甜丝丝。

【场景三：小松鼠来买面包】
[音色:茉莉]
（欢快、蹦蹦跳跳的语气）
小松鼠蹦蹦跳跳跑来。

"伯伯，我要红云面包。"

[音色:冰糖]
（暖意融融）
咬一口，暖呼呼，香喷喷。

【场景四：伯伯想新花样】
[音色:冰糖]
（平静中透着一丝焦虑）
这一天，云朵伯伯皱起眉头。

[音色:苏打]
（自语、思考）
"老口味卖腻了，得整个新花样。"

[音色:冰糖]
（生动）
他挠挠头，想啊想。

突然——

（呼——）

一阵风吹过。

把树叶的绿味儿吹进了店里。

[音色:苏打]
（豁然开朗、兴奋）
"对了！做个绿叶子面包！"

【场景五：绿叶子面包出炉】
[音色:冰糖]
（轻柔、有动作感）
他摘下最嫩的叶子。

轻轻揉进面团里。

烤箱——

[音效：叮]

绿油油的面包出炉了。

【场景六：小动物们抢购】
[音色:茉莉]
（惊喜、好奇）
小兔子闻着味儿钻进来。

"哇！这是什么味儿？"

[音色:苏打]
（大方、邀请）
云朵伯伯递过去一个。

"尝尝看，新口味。"

[音色:茉莉]
（咬一口后，惊叹）
小兔子咬一口。

眼睛亮了。

"咦？有草地的味儿！有露水的甜！"

[音色:茉莉]
（急切、开心）
小松鼠也跑来凑热闹。

"给我来一个！"

[音色:茉莉]
（扇翅膀、急不可待）
小鸟扇着翅膀排队。

"我也要！我也要！"

[音色:冰糖]
（热闹、快节奏）
转眼间，绿叶子面包卖光了。

[音色:苏打]
（乐不可支）
云朵伯伯乐得合不拢嘴。

"新口味真受欢迎！"

【场景七：新的期待】
[音色:冰糖]
（温柔、留白）
第二天，他又琢磨新花样。

雨滴味？雪花味？还是彩虹味？

[音色:茉莉]
（轻轻地、像在跟小朋友贴贴耳朵）
小朋友，你觉得下一个会是什么味儿？
