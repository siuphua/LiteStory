# 《彩虹有几条颜色》TTS 剧本

【场景一：奶奶的小院子】

[音色:冰糖]
（温暖讲故事语气）
下雨停了，天晴了。小白兔兔兔，站在奶奶家的小院子里。

[音色:冰糖]
（轻松愉快）
奶奶在院子里洗菜。水花溅起来，亮晶晶的。兔兔蹲在旁边，等奶奶洗完菜，带她去河边玩。

[音色:冰糖]
（语气一转，像发现了什么）
突然，她抬起头。

[音效：风声渐起]

[音色:冰糖]
（惊喜）
哇！天边挂着一道大彩带。红红的、黄黄的、蓝蓝的，一大片，弯弯曲曲，像一座看不见的桥。


【场景二：兔兔和奶奶看彩虹】

[音色:茉莉]
（兴奋，蹦蹦跳跳）
"奶奶，你看，彩虹！"

[音效：小兔子跳跳声]

[音色:冰糖]
（旁白）
兔兔跳起来，小尾巴一甩一甩。

[音色:苏打]
（慈祥微笑）
"是呀，好大的彩虹。我们的小白数一数，彩虹有几条颜色？"


【场景三：数颜色】

[音色:茉莉]
（自信满满，抢着回答）
"我知道！是七种！红、橙、黄、绿、青、蓝、紫！老师说的！"

[音色:苏打]
（温柔，摸摸她的耳朵）
"是呀，人家都这么数。不过，颜色宝宝手拉手，有时候还会混在一起呢。你要不要自己再数一数？"

[音色:冰糖]
（旁白）
兔兔点点头，站得直直的。她睁大眼睛，从最外面那条宽宽的红色开始数。

[音色:茉莉]
（认真数数，慢慢来）
一，红。二，橙。三，黄。四，绿。

[音色:冰糖]
（旁白，语气带一点困惑）
数到第五、第六的时候，她的小眼睛眯了起来。

[音色:冰糖]
（轻声）
蓝呢？青呢？蓝挨着紫，紫又挨着蓝。它们好像在天空里抱在一起，你一分开，它们又混回去了。


【场景四：兔兔的疑问】

[音色:茉莉]
（歪着小脑袋，有点困惑）
"奶奶，彩虹到底是七种颜色，还是数不清的颜色呀？"

[音色:冰糖]
（旁白）
奶奶把她抱起来，让她站在自己肩上。

[音色:苏打]
（温和而认真）
"你看，彩虹不是彩笔画出来的，它是整片天空的光。细细地看，里面藏着好多好多颜色，比我们说的七种还要多得多。"


【场景五：彩虹消失了】

[音色:冰糖]
（旁白，轻柔）
兔兔眨眨眼睛。她发现，颜色真的像奶奶说的，手拉着手，一个靠着另一个，怎么也分不开。

[音效：微风吹过]

[音色:冰糖]
（旁白，像在看远处）
太阳从云朵后面探出头来。那道大彩带，慢慢变浅了，最后和天边的云连成了一片。

[音色:茉莉]
（若有所思，带着期待）
今天我数出了七种颜色，也看见了数不清的颜色。下一次雨停了，我还要去看彩虹，数一数，天里面到底藏着多少颜色。
