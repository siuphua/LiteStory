# 《秋分的礼物》TTS 剧本

【场景一：秋天的森林】
[音色:冰糖]
（温暖讲故事语气）
秋天到了，白天和晚上变得一样长。
小松鼠从洞里探出头，看见树叶变成了红色和黄色。

【场景二：树爷爷的解释】
[音色:苏打]
（慢悠悠的、慈祥）
今天是秋分。秋分就是白天和晚上手拉手，一样多的一天。

[音色:茉莉]
（好奇、眨眨眼）
那树爷爷，您有礼物吗？

[音色:冰糖]
（描述画面）
树爷爷笑了，笑声像风吹过树叶，沙沙的。

[音色:苏打]
（笑着、慢悠悠）
礼物？秋分的礼物，不是藏在盒子里的。

[音色:茉莉]
（歪着头、不太明白）
不是藏在盒子里的？那是什么呀？

【场景三：白天和月亮的公平】
[音色:苏打]
（伸长树枝、指着远方）
你看。太阳慢慢走过来，白天变长了。
又指着西边——月亮慢慢走过来，夜晚也变长了。
它们轮流陪我们，谁也不偏心。

[音色:茉莉]
（恍然大悟）
所以礼物是公平？

[音色:苏打]
（温和地、慢慢说）
对呀。秋分告诉我们，要和别人分享。
你有坚果，我有树叶，大家一起用，森林才暖和。

【场景四：小松鼠的回礼】
[音色:冰糖]
（描述画面）
小松鼠想了想，从树洞里掏出几颗橡果。

[音色:茉莉]
（认真、诚恳）
树爷爷，这些给您。

[音色:苏打]
（轻轻的、温柔）
谢谢你，小松鼠。明年春天，这里会长出新的小树苗。

【场景五：彩色的蝴蝶】
[音色:冰糖]
（温柔、像在看一幅画）
风轻轻吹过，树叶落下来，像彩色的蝴蝶在跳舞。
小松鼠坐在树爷爷的肩膀上，看着太阳和月亮换班。

[音色:茉莉]
（小声、满足）
树爷爷，秋分的礼物真好。

[音色:苏打]
（慈祥、轻轻笑）
是呀，最好的礼物就是和喜欢的人一起分享。
