# 《泥土里住着一个声音》TTS 剧本

【场景一：乡下院子的清晨】
[音色:冰糖]
（温暖讲故事语气）
小豆豆家在乡下，家里有个大大的院子。

院子里种着花，也长着草。小豆豆最喜欢蹲在花坛边上。

花坛边上有一块软软的泥土地，泥土是棕色的，小小的。

【场景二：神奇的相遇】
[音色:冰糖]
（温暖讲故事语气）
有一天，小豆豆蹲在花坛边，把耳朵贴到了泥土上。

（呼呼——）

忽然，她听见了细细的声音。

（窸窸窣窣……）

[音色:茉莉]
（惊讶）
是谁？谁在说话？

[音色:冰糖]
（温和）
那个声音很轻很轻，像小虫子在唱歌。

[音色:白桦]
（轻柔、羞涩）
是我呀，是一颗小种子，我住在这里好久了。

[音色:茉莉]
（好奇、眨眼）
你会说话？

[音色:白桦]
（温柔、带点孤单）
会呀，可是我好孤单，好久好久，都没有人来听我说话了。

[音色:茉莉]
（轻声、关心）
那你需要我做什么呢？

[音色:白桦]
（期待、小心翼翼）
能给我一点水吗？

[音色:冰糖]
（温暖）
小豆豆跑回家，拿了一个小杯子，接了半杯水。

她端着杯子，轻轻地、轻轻地走回花坛边，把水浇在泥土上。

（咕嘟咕嘟——）

[音色:白桦]
（舒服、开心）
水慢慢地渗进泥土里，我的身体湿湿了，好舒服，谢谢你。

【场景三：第二天的阳光】
[音色:冰糖]
（温暖）
第二天，小豆豆又蹲在花坛边。

[音色:茉莉]
（关切）
小种子，你今天好一些了吗？

[音色:白桦]
（好转、还有点冷）
好一些了，可是天太冷了，你能让我晒晒太阳吗？

[音色:冰糖]
（温暖）
小豆豆想了想，把旁边一块大大的石头，慢慢地、轻轻地搬开了。

阳光暖暖的，照在泥土上。

[音色:白桦]
（暖洋洋、笑）
暖洋洋的，谢谢你，小豆豆。

【场景四：日日夜夜的守护】
[音色:冰糖]
（平缓、有节奏）
第三天，第四天，小豆豆每天都来看小种子。

有时候她问——

[音色:茉莉]
（轻声）
你好吗？

[音色:白桦]
（平静）
嗯，好多了。

[音色:冰糖]
（叙述）
有时候雨下得太大，小种子会说——

[音色:白桦]
（有点喘不过气、求助）
水太多了，我有点喘不过气，能帮我挡一挡吗？

[音色:冰糖]
（温暖）
小豆豆就找来一片大大的叶子，轻轻地盖在泥土上。

[音色:白桦]
（感激、舒服）
谢谢你，像给我盖了一床软软的被子。

【场景五：小蚂蚁的见证】
[音色:冰糖]
（温和）
小蚂蚁路过的时候，也对小种子说——

[音色:苏打]
（赞赏、慢悠悠）
你真好，小豆豆每天都来跟你说话。

[音色:白桦]
（开心、认同）
是啊，她每天都会来听我说话。

【场景六：第七天的奇迹】
[音色:冰糖]
（期待感）
第七天早上，小豆豆像往常一样，蹲在花坛边。

这一次，她没有听见“窸窸窣窣”的声音。

[音色:茉莉]
（担心、喊）
小种子？小种子，你在吗？

[音色:冰糖]
（紧张）
她等了等，等了好久，小种子一直没有回答。

[音色:茉莉]
（内心独白、担心）
小种子是不是睡着了，还是怎么了？

（噗——）

[音色:冰糖]
（惊喜）
泥土弹开了一小片。

一根细细的、绿绿的小芽，顶出了泥土。

小豆豆瞪大了眼睛，一动不动地看着。

[音色:白桦]
（清亮、开心）
是我呀，谢谢你，每天都来听我说话。

[音色:茉莉]
（笑、眼睛弯弯）
（笑声）

【场景七：新的开始】
[音色:冰糖]
（温暖、充满希望）
第二天，小豆豆又听见了细细的声音。

[音色:白桦]
（得意、晃动感）
我长大了一点点，风一吹，我就轻轻晃，你能听见吗？

[音色:茉莉]
（开心、肯定）
能听见，你晃起来的样子，好可爱。

[音色:冰糖]
（温馨）
那天晚上，小豆豆对着花坛说——

[音色:茉莉]
（轻柔、晚安）
小芽，晚安。

[音色:冰糖]
（画面感）
小芽轻轻晃了晃，像是在点头。

（沙沙——风吹叶子声）

[音色:冰糖]
（深情、收束）
从那天起，小芽一天天长高，还长出了小小的叶子。

小豆豆每天，都会蹲在旁边，听它说话。

小豆豆发现了一个秘密：每一个小小的生命，都在用自己的方式说话。

只要你蹲下来，把耳朵贴过去，就能听见。

（停顿）

再小的声音也值得被听见，愿意停下来倾听，就是最大的温柔。
