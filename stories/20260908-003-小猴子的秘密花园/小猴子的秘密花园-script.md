# 《小猴子的秘密花园》TTS 剧本

【场景一：清晨的榕树家】
[音色:冰糖]
（温暖讲故事语气）
大森林里，最高的那棵榕树上，住着一只小猴子，叫咕咕。

[音色:冰糖]
（轻快）
一天清早，咕咕醒来。阳光从树叶缝里偷偷溜进来，金灿灿的，暖洋洋的。

[音色:茉莉]
（开心、舒展）
“今天天气真好！”

[音色:冰糖]
（轻快）
咕咕伸个懒腰，翻个身，蹦蹦跳跳跑出树洞。

【场景二：发现秘密花园】
[音色:冰糖]
（叙述、带点神秘感）
咕咕跑啊跑，跑过小溪，跑过草地。忽然，他看见一扇门——一扇旧旧的、绿油油的木门，藏在藤蔓后面，藏在花丛里，像是专门躲着不让人发现。

[音色:茉莉]
（好奇、压低声音）
咕咕好奇了。他轻轻推开门……吱呀——

[音色:冰糖]
（惊叹、缓慢）
门开了。哇！里面是个花园。不是普通的花园——这里的花会发光！粉色的、蓝色的、金黄的。花朵轻轻摇摆，发出叮叮当当的响声，像风铃，又像小星星在唱歌。

[音色:冰糖]
（惊奇）
中间立着一棵树，树上结满了果子。果子圆滚滚，五颜六色：红的像小灯笼，黄的像小月亮，紫的像小葡萄。风一吹，果子晃悠悠，还会哼哼小曲儿。

【场景三：独自享受】
[音色:茉莉]
（兴奋、得意）
“哇！这是我的秘密花园！”

[音色:冰糖]
（叙述）
咕咕摘一个红果子，咬一口。甜滋滋，香喷喷，汁水顺着嘴角流下来。咕咕笑得眼睛眯成缝。

[音色:茉莉]
（得意、自言自语）
“这些都是我的！全都是我的！”

[音色:冰糖]
（叙述、语速放缓）
太阳偏西了，影子拉得长长的。咕咕坐在发光花旁，啃着果子。可渐渐地，他不太乐了。

[音色:冰糖]
（安静、略带空旷感）
花园里安静极了。只有风声，只有果子哼曲儿的声音。

[音色:茉莉]
（对着空气、有点傻笑）
“好吃！真好吃！”

[音色:冰糖]
（平淡、无人回应）
没有人回答。没有人跟他一起笑。也没有人跟他抢着说：“我要尝尝！”

[音色:茉莉]
（失落、小声）
“要是有人陪我就好了。”

【场景四：小松鼠出现】
[音色:冰糖]
（轻快、有动感）
这时候——沙沙沙——藤蔓动了。钻出一只小松鼠，尾巴竖得高高的，像个问号。

[音色:白桦]
（兴奋、嗅觉灵敏）
“喂！那边传来好香的味儿。”

[音色:冰糖]
（叙述）
小松鼠鼻子动动，眼睛亮晶晶。

[音色:茉莉]
（吓到、慌张、结巴）
“没、没有！我不吃果子！”

[音色:冰糖]
（叙述）
咕咕赶紧把果子往身后藏。

[音色:白桦]
（可怜、撒娇）
“真的吗？那我肚子饿得咕咕叫。能不能分我半个？就半个。”

【场景五：分享快乐】
[音色:冰糖]
（叙述、心理变化）
咕咕看看小松鼠，又看看手里的果子。红果子只剩一半了。他想起刚才的孤单，想起没人陪他笑。

[音色:茉莉]
（下定决心、温柔）
“好吧。给你。”

[音色:冰糖]
（叙述）
咕咕把黄果子递过去。小松鼠接过果子，大口咬一口，眼睛立马弯成月牙。

[音色:白桦]
（惊喜、开心）
“哇！甜！太好吃了！谢谢你，咕咕！你真好！”

[音色:茉莉]
（开心、心里暖暖的）
咕咕看着小松鼠笑。心里突然暖洋洋的，比吃果子还甜。

[音色:茉莉]
（邀请、大方）
“你要不要坐下来？这儿有会唱歌的花，会哼曲儿的果子。”

[音色:白桦]
（高兴答应）
“好呀！”

[音色:冰糖]
（轻快、画面感）
小松鼠屁颠屁颠跑过来，两个小家伙并排坐着。风一吹，花叮叮当当响，果子晃悠悠，哼起小曲。

[音色:茉莉]
（分享、快乐）
“来，一起吃。”

[音色:冰糖]
（温馨、画面感）
咕咕把紫果子掰开，一半给小松鼠，一半自己吃。小松鼠咬一口，咕咕咬一口，汁水混在一起，甜在心里。两个小家伙笑得前仰后合，声音惊飞了树上的鸟，也惊醒了午睡的蝴蝶。

【场景六：告别与回家】
[音色:冰糖]
（温柔、傍晚氛围）
天色晚了。小松鼠要回家了。

[音色:白桦]
（依依不舍、期待）
“咕咕，明天我还来找你！我带松果给你吃！”

[音色:茉莉]
（开心答应、大方）
“好呀！我留最甜的果子给你！”

[音色:冰糖]
（叙述、感悟）
咕咕看着小松鼠蹦蹦跳跳远去。心里不空了，踏实极了。独自走回榕树家，路过小溪，溪水哗啦啦唱歌；路过草地，虫儿齐齐整整合唱。原来，森林里到处都是音乐。原来，分享出去的快乐，会变成更多的快乐，跑回来找你。

【场景七：美梦结尾】
[音色:冰糖]
（轻柔、催眠感）
咕咕钻进树洞，合上眼。梦里，花园里的花更亮了，果子更甜了，还有小松鼠的笑声，叮叮当当，钻进梦里。
